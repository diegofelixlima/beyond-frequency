# Beyond Frequency: Knowledge Graphs for Fashion Trend Analysis

This repository contains the full experimental pipeline for the paper:

> **Além da Frequência: Grafos de Conhecimento para Análise de Tendências de Moda**
> Diego Félix Beserra de Lima — UFCG, Programa de Pós-Graduação em Ciência da Computação

This work investigates whether responses about fashion trends generated with the support of a knowledge graph (KG) are more interpretable and grounded than responses generated directly from raw text by a large language model (LLM).

---

## Research Question

> To what extent are responses about fashion trends generated via a knowledge graph more interpretable and grounded than responses generated directly from raw text by a large language model?

## Reproducing the Experiment

The experiment is designed to run entirely in **Google Colab** — no local installation required.

### Step 1 — Open the notebook

1. Go to [Google Colab](https://colab.research.google.com)
2. Open via **File → Open notebook → GitHub**
3. Enter: `https://github.com/diegofelixlima/beyond-frequency`
4. Select `notebooks/experiment.ipynb`

### Step 2 — Add your OpenAI API key

1. In the left sidebar, click the key icon (**Secrets**)
2. Add a new secret: `Name: OPENAI_API_KEY` / `Value: your_key_here`
3. Enable access to the notebook

### Step 3 — Run all cells in order

| Step | Script | Description |
|---|---|---|
| 0 | Setup | Install dependencies and clone repository |
| 1 | 01-clean.py | Clean raw reviews, extract editorial content |
| 2 | 02-extract-triples.py | Extract semantic triples via OpenAI API |
| 3 | 03-build-kg.py | Build knowledge graph with NetworkX |
| 4 | 04-query.py | Run comparative experiment (Condition A vs B) |
| 5 | Inspect | Compare responses side by side |
| 6 | Save | Download results as zip |

## Experimental Design

| | Condition A | Condition B |
|---|---|---|
| Input | Raw text | Knowledge graph triples |
| Processing | LLM reads text directly | LLM queries structured graph |
| Output | Narrative response | Graph-grounded response |

**Evaluation questions:**
- P1 (intra-document): "What are the dominant trends in this collection?"
- P2 (intra-document): "What relations between elements characterize these trends?"
- P3 (inter-document): "What trends dominated London AW25?"

**Evaluation metrics:** Likert scale (1–5) on two dimensions:
- **Interpretability:** is the response clear and comprehensible?
- **Groundedness:** does the response support claims with concrete elements?
